# GA 事件標示頁

把舊版（`mirror/`）與新版（`redesign/`）的首頁、ES 車款頁（舊版另有展開的「選單」頁）放在同一個畫面，
在頁面上直接標出要埋 GA4 自訂事件的位置，並提供事件內容與可複製的程式碼給前端。

網址：`/ga/`（可用 `#v=mirror|redesign&p=home|es&d=mobile` 直接指定畫面）

## 前端怎麼看
1. 選版本、頁面、裝置，頁面上的編號標記就是要埋事件的位置。
2. 點標記，或從右側「本頁標記」清單點選，看事件內容、參數，複製 `data-track` 屬性與 gtag 程式碼。
3. 「共通規則」視窗可填入研究用 GA4 資源的評估 ID（程式碼會跟著更新），並可複製 GA 基礎追蹤碼（gtag.js）。

## 怎麼標記（編輯模式）
1. 打開「編輯模式」。
2. 到右側「事件庫」挑事件按「放置標記」，在頁面上拖曳畫出範圍（點一下則放預設大小）。
3. 在右側填「元件說明」、選參數。標記可拖移、拉大縮小，`Delete` 鍵或「刪除標記」可移除。
4. 固定在畫面上的元件（頁首、側邊快捷）放置時勾「固定在畫面上」。
5. 桌機（1440 寬）與手機（390 寬）的標記各自記錄，需分別標示。
6. 編輯模式下頁面不能點擊；要操作頁面請先關閉編輯模式。

## 儲存
- 標記先存在這台瀏覽器（草稿）。標完按「匯出標示」，取得 `annotations.json`，放進 `ga/` 後推上去，其他人才看得到。
- 「放棄草稿」會清掉瀏覽器裡的草稿，改回已發佈的版本。

## 事件內容
事件、參數、可用值與說明在 `events.js`，依「Lexus官網_GA4自訂事件埋設規劃」草稿 v0.1。
