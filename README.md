# LEXUS 專案

靜態網站，直接部署到 GitHub Pages（https://ml-kevincy.github.io/lexus/），無需建置。

## 結構
```
index.html      專案索引（入口頁）
wireframe/      線框原型 v3.0（首頁、ES 車款介紹、0722 提案版）— 說明見 wireframe/README.md
mirror/         現行官網鏡像，供 Maze 易用性測試 — 說明見 mirror/README.md
redesign/       新版設計（依 PSD 製作，Maze 對照用）— 說明見 redesign/README.md
tools/mirror/   鏡像擷取工具
tools/redesign/ PSD 素材切圖與資料產生工具
.nojekyll       關閉 Jekyll，保留底線開頭的資料夾（mirror/_api 等）
```
